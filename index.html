⚙ 設定

禁字清單管理
支援以「分類」管理禁字。每行一個詞；以 == 分類名稱 == 起頭代表新增分類。已內建示範清單，等你提供完整清單後可整批貼上覆蓋，或匯入 JSON。
AI 模型設定
部署 Worker 後會拿到一段 *.workers.dev 網址，貼在這裡。
Anthropic 建議：claude-sonnet-4-5；OpenAI 建議：gpt-4o-mini（便宜）或 gpt-4o（較強）。
Proxy 模式說明：API Key 由管理員設在 Cloudflare Worker 的環境變數，前端只會傳「使用密碼」與文章內容過去。Worker 會檢查密碼、做每日呼叫上限，再代為呼叫 Anthropic。最安全、可控、零金鑰外洩風險。
直連模式注意：從瀏覽器直接打 API。Anthropic 會自動帶 dangerous-direct-browser-access header；OpenAI 預設可直接呼叫。Key 會存在這台電腦的 localStorage。

使用說明

工作流程

  1. 第一次使用先進入 ⚙ 設定，填入 API Key 並依需求調整禁字清單。
  2. 把員工寫的文章貼到左側輸入框，規則檢查會即時執行（停止輸入 0.5 秒後）。
  3. 右側分頁可切換查看：禁字命中、通順度問題、SEO 結構、標記預覽（標紅版）、AI 建議。
  4. 確認需要 AI 二次審閱時點擊「✨ AI 智慧檢測」。

分類嚴重度

名稱含「絕對」「禁用」「不可」「重大」會被視為 高嚴重度（紅色），其餘為 中嚴重度（黃色）。

資料保存

禁字清單、API Key、稽核提示詞都儲存在這台電腦的瀏覽器內（localStorage），不會上傳到任何伺服器。

部署建議

單檔 HTML，可直接放在公司內網、Notion 附檔、Google Drive 共享，或用 GitHub Pages 部署成內部網址。
